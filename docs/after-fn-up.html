the path

fn upt = 0

stop the capture endRecording · capture.stop()

the 16 kHz float buffer comes back whole. the output device is unmuted, and the stop cue plays 80 ms later because a sound played in the same instant as the unmute is lost.

exit if the recording is under 0.3 s or its peak is under 0.01: discarded, back to idle, nothing typed. Fixed.minimumRecordingSeconds · silencePeak

remember where you are Frontmost.capture() · RecordingArchive.save

the app, window title and a new history id are taken now, before any await, so the entry can say where the text went even if focus moves. the audio is written to the archive under that id.

transcribemedian 147 ms

speech to text Transcriber.transcribe · parakeet 0.6b

the pill shows transcribing. parakeet runs the whole buffer in one pass, about 3% of the audio's length. the result is the transcript as heard: lowercase, unpunctuated, fillers and all.

exit if the result is blank, or if a new recording started meanwhile: the generation counter no longer matches and this task returns without touching anything. gen == generation
clean upmedian 929 ms

the model and the code around it PostProcessor.clean

the pill shows cleaning up. this is the one function the eval scores, so what the eval sees is what gets typed.

1 before the modelletters spoken one at a time join into an acronym, so the false-start rule cannot delete them. joinSpelledLetters
2 the promptthe rules as session instructions, plus the screen terms and any style rule the user turned on; the transcript alone inside tags as the user message; custom words after it.
3 apple intelligenceguided generation into one field, greedy sampling. the eight fixes: mishearings, spelling, digits, currency, spoken punctuation, um and uh, false starts, keep the language.
4 the guardsoutput rejected as a rewrite if too few words survive or it grows past 2.5×, and rejected if the opening words are gone. rejected means the transcript as heard is used instead. looksLikeRewrite · lostOpening
5 after the modeladjacent words that spell a screen term or custom word become it. fuseTerms
6 writing stylesin code, on whatever came out: fillers cut, lists built, contractions joined, reported speech quoted, numbers to digits, then currency symbols and the trailing full stop dropped. WritingStyle.apply
skip from the pill, or esc, cancels the model call; skip types the transcript as heard, esc types nothing. the generation check runs again after the await.

look at the focused element Focus.focusedElementIsTextInput

a trailing space is added. then accessibility is asked whether the focused element is a text input: yes, no, or no answer. the answer decides what happens after the paste, not whether it happens.

paste120 ms fixed

type it Output.paste

the clipboard's text (or image) is saved, the transcript put on it, 60 ms wait, cmd+v posted as a system event, 60 ms wait, and the clipboard restored. with auto-submit on, return is posted 50 ms later with the chosen modifier.

if cmd+v could not be posted, accessibility is missing: the paste reports false and the copy prompt takes over below.
+0 ms

write history, go idle store.append · phase = .idle

one entry with the transcript as heard, the cleaned text, both durations, the app and window, and the recording file. the pill hides and the next fn down is accepted.

  • focused element was a text input: read-back starts, watching the field for your corrections to learn from. ReadBack.start
  • not a text input, or the paste failed: the pill offers copy for 8 s instead. showCopyPrompt

the settings on this path

every setting the happy path assumes is on, with what turning it off removes. the eval runs with all of them on except keep recordings and auto-submit, which do not touch the text.

settingdefaultwhat it does here
muteWhileRecordingonthe output device was muted at fn down; fn up restores it, and the stop cue waits 80 ms for the device to come back.
audioFeedbackonthe stop cue itself.
keepRecordingsdev on, release offwrites the audio next to the history entry. off, nothing is saved and there is nothing to play back in history.
postProcessingEnabledonthe whole clean-up step. off, the transcript as heard goes straight to the paste and no style applies.
screenContextEnabledoffthe screen read lane. needs screen recording. off, the model gets no screen terms and nothing is fused after it.
customWordsemptylisted after the transcript in the prompt, and fused in code after the model.
writingStylesnonedigits, cut filler words, contractions, lists, quotes. filler words and contractions also add a rule to the prompt; the rest are code only.
appendTrailingSpaceonthe space after the text, so the next dictation does not run into this one.
autoSubmit · autoSubmitKeyoff · returnreturn, ctrl-return or cmd-return 50 ms after the paste.
learnFromCorrectionsonread-back after a paste into a text input. skipped in password managers and terminals, and while secure input is on.
copyPromptEnabledonthe copy pill when the paste had nowhere to go.
historyLimit500how many entries the history keeps; the oldest go, with their recordings.

not on this page

esc at any point, the model being unavailable or still downloading, the learned-words toast that read-back can raise later, and the model unload five minutes after the last dictation. the eval's wish list holds the cases where this path does not yet produce the text it should.
