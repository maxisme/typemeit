the subordinate cut · round 6

subordinate, tuned. 0.82× was my first guess, not a considered number — these ladders are for picking the real one. read each ladder down; only the labelled value changes between rows. the marked row is my pick.

shrinking the name has one consequence worth knowing up front: the gap is measured off the mark, not the name, so as the name gets smaller the gap silently gets wider relative to it. that is why there is a gap ladder below the ratio one.

0.34em. the puff's outline is not a straight edge — the lobe nearest the name curves away from it, so a gap that measures correctly still looks too wide. 0.34 measures tight and looks right, which is the only test that matters.

3 · the weight

a smaller name is also a lighter one — the same weight set smaller puts less ink on the page, so the name can end up quieter than intended rather than merely smaller. this is the one place subordinate might want a weight it did not before.

the honest finding: at 11 and 13 px the name is only about 9 and 11 px tall, and dm mono 400 goes thin there. those two use 500, which is the one exception the cut needs — a small-size variant, the way the puff already has a stroke-5 cut for the same reason. everything at 18 px and up is 400.

the cut, in full: puff at its own stroke weight; name dm mono 400 at 0.84× the mark's scale, gap 0.34em, fitted (t −0.07em, i −0.11em, y −0.03em), dropped 0.03em; weight 500 and the stroke-5 puff below 18 px.
