wordmark studies · round 1

ten ways to set the name beside the puff. every one is built from what the system already owns — one ink, one paper, dm mono set lowercase, hairlines, and the two emphasis moves the system allows (invert, italic). nothing new is introduced: no second face, no accent, no third weight.

each plate shows the lockup large, then the same lockup at 13 px on paper and inverted on an ink slab — menu bar size and dark hero, the two places a mark for this app actually has to hold up.

mark, air, name. the gap is one lobe wide, so the puff reads as the first word of the line rather than an icon bolted to the front of it. the workhorse — menu bar, readme, github social preview.
